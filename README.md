# 오늘 운동 — v3.4.1

운동 종목과 루틴을 자유롭게 만들고, 세트별 수행 내용과 날짜별 운동 기록을 관리하는 무료 웹앱입니다.

**앱 접속:** https://workout-record-v30-mobile.vercel.app/

> 앱 기능 버전은 **v3.4**입니다. URL의 `v30`은 기존 Vercel 프로젝트 이름으로, 현재 기능 버전을 뜻하지 않습니다. 개인 기록은 서버가 아니라 **사용 중인 기기의 브라우저 저장소**에 보관됩니다.

## 주요 기능

| 메뉴 | 주요 기능 |
| --- | --- |
| **오늘 운동** | 워밍업 시작시간·타이머, 운동 종목·루틴 추가, 목표 및 실제 중량·횟수·운동시간 기록, 세트 완료, 운동 완료 및 다시하기 |
| **기록** | 날짜별 운동 기록, 시작·완료 시각, **총 운동시간**, 세트별 결과, 운동결과 텍스트 복사 |
| **운동 목록** | 중량운동·맨손운동·유산소 종목명과 종류를 등록, 목표는 루틴에서 관리 |
| **루틴** | 운동 종목 조합, **종목별 중량·횟수·세트 설정**, 루틴 저장·사용, **텍스트로 루틴 추가** |
| **설정** | 목표 메모, **운동 백업**, 백업 가져오기, 홈 화면에 설치 |

운동을 완료하면 컨디션·피로감·메모를 남길 수 있습니다. 지난 운동 기록은 읽기 전용으로 확인할 수 있습니다.

### 휴식 타이머

- 중량운동·맨손운동은 설정한 휴식시간을 세트 사이에 사용합니다. **마지막 세트를 완료한 뒤에는 휴식 타이머가 자동 실행되지 않습니다.**
- 타이머 종료 시 운동을 이어갈지 묻는 창 없이 자동으로 닫힙니다.
- **유산소 운동에는 별도의 휴식시간 설정이 나타나지 않습니다.**
- 알림 소리·진동 등은 기기와 브라우저의 지원 및 백그라운드 동작 제한에 따라 다를 수 있습니다.

### 총 운동시간 (v3.2)

운동을 완료한 기록의 목록과 상세 화면에서 시작 시각, 완료 시각과 함께 총 운동시간을 확인할 수 있습니다.

예: `시작 14:10 ~ 완료 15:25 · 총 운동시간 1시간 15분`

종료되지 않은 운동은 진행 중으로 표시하며, 과거 기록에 유효한 시각 정보가 없으면 소요시간을 임의로 만들지 않습니다.

## 텍스트로 루틴 추가 (v3.1)

**루틴 → + 텍스트로 루틴 추가**를 선택하고 루틴 이름 및 운동 목록을 입력합니다. **한 줄에 세트 구간 하나**를 작성하며 같은 운동명을 여러 줄 적으면 한 운동으로 합쳐집니다.

형식: `운동 종목 / 무게 또는 운동 종류 / 횟수·시간 / 세트 수`

```text
바벨 스쿼트 / 40kg / 10개 / 3세트
랫풀다운 / 35kg / 12개 / 4세트
푸시업 / 맨손 / 15개 / 3세트
플랭크 / 맨손 / 1분 30초 / 3세트
러닝 / 유산소 / 30분 5km 130bpm / 1세트
```

- 중량운동은 `스쿼트 / 40 / 10 / 3`처럼 kg·개·세트 단위를 생략할 수 있습니다.
- 맨손운동은 반복 횟수 또는 유지시간(예: `1분 30초`)을 입력할 수 있습니다.
- 유산소는 운동시간(분)이 필수이며 거리(km)와 평균심박(bpm)은 선택사항입니다.
- **같은 운동 이름을 여러 줄 입력하면 한 종목으로 묶습니다.** 일반적인 띄어쓰기 차이뿐 아니라 보이지 않는 특수문자·한글 유니코드 조합 차이도 정규화해 비교합니다. 줄 순서대로 세트별 중량·횟수를 유지합니다. 예: `바벨스쿼트 / 20 / 10 / 1`, `바벨스쿼트 / 40 / 8 / 4`, `바벨스쿼트 / 50 / 5 / 1` → 총 6세트짜리 바벨스쿼트 하나.
- 기존 운동 목록에 이름·종류·측정 방식이 같은 종목이 있으면 재사용합니다. 목표 중량이 달라져도 운동 목록에 새 종목을 계속 만들지 않습니다. **세트별 계획은 루틴마다 별도로 저장**되므로 다른 루틴이나 과거 기록을 바꾸지 않습니다.

### 이미 10종목으로 저장된 루틴 수정 (v3.3.1)

기존 루틴에서 같은 운동이 별개의 ID로 저장되어 있으면 **루틴** 카드에 **중복 종목 합치기** 버튼이 나타납니다. 확인 후 클릭하면 같은 운동명·종류·측정 방식인 종목을 하나로 합치고, 각각에 저장된 세트별 목표를 원래 순서대로 연결합니다. **해당 루틴만 수정**하며 운동 목록의 종목이나 이전 수행 기록·다른 루틴은 변경하지 않습니다. 버튼이 보이지 않으면 현재 알고리즘으로 판단되는 합칠 대상이 없다는 뜻입니다.

## 시간 유지 맨손운동 타이머 (v3.4 추가)

- **플랭크 등 맨손운동 중 ‘유지 시간’ 방식**에서 미완료 세트의 체크 버튼(▶)을 누르면, 체크가 즉시 완료되지 않고 **실제 운동시간 카운트다운**이 시작됩니다.
- 기존 휴식 타이머와 유사한 원형 UI지만 **붉은색 원이 0%에서 100%로 차오르며**, 남은 시간이 함께 표시됩니다. 운동 도중에는 작게 보기 또는 운동 취소를 선택할 수 있습니다.
- 정해진 시간이 지나야 해당 세트가 자동으로 완료됩니다. **같은 종목에 뒤에 남은 세트가 있을 때만** 기존 휴식 타이머가 즉시 시작됩니다. 마지막 세트에는 휴식 타이머가 시작되지 않습니다.
- 진행 중 취소하면 해당 세트는 **미완료**로 유지됩니다. 다음 세트 진행 전에 취소·완료해야 하며, 다른 세트를 동시에 완료할 수 없도록 보호합니다.
- 타이머 종료 예정 시각을 그날 운동 세션에 저장하므로 PWA를 잠시 닫거나 백그라운드에 둔 뒤에도 남은 시간을 다시 계산합니다. 앱을 오래 닫아두었다가 돌아오면 이미 지난 휴식시간을 처음부터 다시 시작하지 않습니다.
- 모바일 웹 브라우저 및 기기 설정에 따라 백그라운드 상태의 소리·진동·자동 전환은 지연되거나 제한될 수 있습니다. 운동시간은 별도의 종료 예정 시각을 기준으로 합니다.
- 체중운동 반복 횟수 방식과 일반 중량운동·유산소운동은 기존 체크 동작을 그대로 사용합니다.

## v3.4 종목·루틴 분리와 워밍업

- **운동 목록:** 운동명, 운동 종류, 유의사항·태그만 등록합니다. 신규 종목은 중량·횟수·세트 목표를 갖지 않습니다. 기존 종목에 남아 있는 기본 세트는 이전 버전 루틴의 호환성을 위해 내부적으로 보존하되, 운동 목록에서 새 목표를 입력하지 않습니다.
- **내 루틴:** 종목별 세트 추가·삭제와 각 세트의 무게·횟수·유지시간·유산소 목표를 수동으로 설정합니다. 같은 종목도 요일·루틴마다 다른 목표를 저장하며, 텍스트로 생성된 루틴의 중량도 편집할 수 있습니다. 새 루틴의 세트별 계획은 `setPlans`에 보관합니다.
- **운동 시작 시각:** 오늘 운동 맨 위의 **워밍업 시작**을 누르는 시각을 운동 시작시간으로 기록합니다. 워밍업은 기본 5분이며 시작 전과 진행 중에 **±5분씩** 조절할 수 있고, 일찍 종료할 수도 있습니다. 앱을 재실행해도 남은 시간은 실제 종료 시각을 기준으로 계산합니다.
- **워밍업 생략:** 종목·루틴을 추가하는 것만으로는 운동을 시작하지 않습니다. 워밍업 없이 첫 세트를 완료하면 그 시각을 운동 시작시간으로 기록합니다. 진행 중 워밍업 상태에서 첫 세트를 완료하면 워밍업을 종료합니다.
- 완료된 과거 세션의 기록은 수정하지 않습니다. 백업은 기존 `schemaVersion: 2` 형식을 유지합니다. 모바일 브라우저 환경에서는 종료 알림의 소리·진동이 제한될 수 있습니다.

## 운동 기록 복사 → 다음 운동 루틴 생성 (v3.3)

**기록 → 날짜 선택 → 운동결과 텍스트로 복사**로 AI 코칭 요청문을 복사해 원하는 AI 대화에 붙여넣습니다. 복사되는 문장 끝에는 **다음 운동을 위한 추천 루틴을 앱 입력 규칙에 맞게 생성해 달라는 요청**이 포함됩니다.

AI가 제안한 루틴의 `text` 코드블록에서 운동 줄만 복사해 **루틴 → 텍스트로 루틴 추가**에 붙여넣으면 됩니다. 같은 운동명 아래 서로 다른 중량 구간을 여러 줄로 적어도 하나의 운동 안에서 세트별 목표로 합쳐집니다.

추천 목표는 AI가 기록의 컨디션·통증·난이도와 실제 달성 여부를 분석해 제안하는 것으로, **증량이 자동 계산되거나 안전이 보장되는 기능은 아닙니다.** 불편함이나 통증이 있다면 목표를 보수적으로 조정하세요.

## 운동 백업과 가져오기 (v3.2~)

### 운동 백업

**설정 → 운동 백업**을 누르면 저장 방식을 선택할 수 있습니다.

1. **기기에 저장:** `workout-backup-YYYY-MM-DD.json` 파일을 저장합니다. 갤럭시에서는 보통 **내 파일 → 다운로드(Download)** 폴더에 들어갑니다. 지원되는 브라우저는 저장 위치를 직접 선택할 수도 있습니다.
2. **클라우드·메일 등으로 공유:** 지원되는 갤럭시·브라우저에서는 기기의 공유 메뉴가 열립니다. Google Drive, Gmail 등 설치된 앱을 선택해 백업 파일을 저장하거나 전송할 수 있습니다.

**주의:** 이 기능은 Google Drive **자동 동기화가 아닙니다.** 사용자가 공유·저장 대상을 직접 선택합니다. 파일 공유가 지원되지 않으면 기기에 다운로드한 뒤 파일 관리 앱에서 클라우드나 메일로 공유하세요. 앱에서 다운로드를 요청했다고 해서 실제 클라우드 저장까지 보장되는 것은 아닙니다.

### 백업 가져오기

**설정 → 백업 가져오기**에서 이전에 저장한 `.json` 파일을 선택하고 복원 확인을 진행합니다. 갤럭시에서는 일반 파일 선택창의 **파일/내 파일 → 다운로드(Download)**에서 `workout-backup-날짜.json` 파일을 찾으세요. Google Drive에 저장한 백업은 파일 선택 화면에서 해당 위치를 찾아 열거나 먼저 기기에 다운로드할 수 있습니다. v3.2.2부터 파일 선택창에 JSON 형식 필터를 걸지 않고, **선택 후에 파일명과 JSON 데이터 구조를 검사**합니다.

⚠️ **백업 가져오기는 합치기가 아니라 전체 교체입니다.** 현재 운동 목록·루틴·기록이 가져온 파일의 데이터로 대체되므로, 복원 전에 현재 상태를 먼저 백업하세요.

앱 내부의 백업 데이터 형식 식별자는 `schemaVersion: 2`이며, 화면 기능 버전 `v3.4`와 서로 다른 개념입니다.

## 개인정보 및 데이터 저장

- 운동 기록은 우선 **IndexedDB**에 저장하며, 지원이 제한될 때 **localStorage**를 대체 저장소로 사용합니다.
- 별도 회원가입·로그인·서버 동기화가 없습니다.
- 다른 기기·브라우저에서 열거나 사이트 데이터를 삭제하면 기존 기록이 보이지 않을 수 있습니다. 백업 파일을 주기적으로 안전한 장소에 보관하세요.
- 통증·컨디션·메모 등은 사용자가 결과를 복사하거나 백업 파일을 공유할 때 외부로 전달할 수 있습니다.
- 웹앱은 의료 진단용 도구가 아닙니다.

- 네이버 서치어드바이저에 등록하려면 네이버에서 발급받은 인증 태그를 별도로 추가해야 합니다.
- **사이트맵:** https://workout-record-v30-mobile.vercel.app/sitemap.xml
- 검색엔진의 실제 색인·검색 노출 여부는 각 서비스에서 확인해야 합니다. 노출 및 순위는 보장되지 않습니다.

## 변경 이력

- **v3.0:** 모바일 사용성 및 SEO·PWA 배포 구성
- **v3.1:** 유산소 휴식 설정 제거, 휴식 타이머 종료 시 자동 닫기, 텍스트로 루틴 추가
- **v3.2:** 운동 백업 저장 위치·공유 선택, 운동 기록의 총 운동시간 표시
- **v3.2.1:** 갤럭시에서 백업 파일 저장 오류 시 다운로드로 전환
- **v3.2.2:** 갤럭시 백업 가져오기 파일 선택 개선 (파일 앱 진입 및 JSON 검사)
- **v3.3:** 같은 운동의 세트별 중량·횟수 구간 자동 통합, 루틴별 목표 저장, 운동기록 복사 시 다음 운동용 루틴 출력 요청 추가
- **v3.3.1:** 보이지 않는 문자·공백 차이로 생기는 같은 운동명 중복 방지, 이미 저장한 루틴에서 **중복 종목 합치기** 기능 추가
- **v3.4:** 종목 등록과 루틴별 목표 분리, 루틴 수동 편집에서 세트별 중량·횟수 입력, 오늘 운동 워밍업 5분 타이머·시작시간 명확화, **맨손 시간 유지 운동의 빨간 운동 타이머 → 휴식 타이머 자동 연결**
- **v3.4.1:** 실행/새로고침 후 진행 중인 지속운동 타이머는 화면을 가리는 팝업 대신 작은 버튼으로 복원. 잘못된/만료된 타이머 상태 검증, 배경 터치 시 작게 보기, 종료 후 휴식 타이머도 복원 시 작은 버튼으로 표시. 휴식·지속운동 원형 타이머의 시간 바로 아래 안내 문구 제거 및 지속운동 원형 아래 문장 간소화. 운동 기록·백업 형식 변경 없음.
