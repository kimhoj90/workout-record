운동 추가

제조사 선택 시 [신코] 롱풀처럼 저장돼. 운동명을 검색해서 선택하거나 직접 입력해도 돼.

운동 목록에서는 종목만 등록해. 목표 무게·횟수·시간·세트는 루틴에서 설정해 줘.

루틴 만들기

루틴에 종목을 추가하고 각 세트마다 무게·횟수·시간을 입력해. 다른 날에는 같은 종목으로 별도 루틴을 만들 수 있어.

텍스트로 루틴 추가

형식: 운동 종목 / 무게 / 횟수 / 세트
중량: 스쿼트 / 40kg / 10개 / 3세트
맨손: 푸시업 / 맨손 / 15개 / 3세트
시간유지: 플랭크 / 맨손 / 1분 30초 / 3세트
유산소: 러닝 / 유산소 / 30분 5km 130bpm / 1세트
같은 운동명을 여러 줄 적으면 하나의 종목으로 합치고, 입력한 순서대로 세트별 중량·횟수를 유지해. 단위(kg·개·세트)는 중량운동에서 생략해도 돼. 운동 이름과 각 항목을 / 로 구분해 줘.

이름의 띄어쓰기·보이지 않는 문자 차이까지 확인해 같은 운동을 묶어. 기존 운동 종목은 재사용하고, 세트별 목표는 이 루틴에만 저장해. 이전 루틴이나 기록은 바꾸지 않아.

운동 다시하기

오늘 운동을 다시 하시겠습니까?

예를 선택하면 오늘 운동의 모든 세트 완료 체크만 초기화돼. 운동 종목·순서·중량·횟수 등 입력값과 메모는 유지되고, 다시 운동을 기록할 수 있어.

운동 백업

운동 기록·운동 목록·루틴을 하나의 백업 파일로 보관해. 저장할 곳을 선택해 줘.

갤럭시에서는 보통 내 파일 → Download(다운로드) 폴더에서 확인할 수 있어. 지원하는 브라우저에서는 저장할 폴더를 직접 선택할 수 있어.

갤럭시 공유 메뉴에서 Google Drive, Gmail 등 설치된 앱을 선택해 줘.
